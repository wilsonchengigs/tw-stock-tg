# tw-stock-tg

每個交易日 21:30（台灣時間）用 GitHub Actions 把台股日報傳到 Telegram，並附上一套正2 波段策略的訊號；收盤後 14:40 若出現「爆量收黑」另外提醒（趕 15:00 夜盤）。另外包含策略研究的回測程式與研究紀錄。

> 研究回測不代表未來報酬，也不是投資建議。

## 日報內容（`report.py`）

| 段落 | 內容 | 來源 |
|---|---|---|
| 大盤 | 加權指數漲跌、小時 K 的 MA20／60／240、成交金額、三大法人買賣超 | 證交所 |
| 融資 | 大盤融資維持率（自算：Σ 個股融資張數×1000×收盤 ÷ 融資金額）、融資餘額增減 | 證交所 |
| 期貨 | 外資台指期淨未平倉 | 期交所 |
| 🧭 策略 | 指數、進場線、出場線、融資過熱濾網（偏離與 z）、應持有什麼、本週是否切換 | 上面資料＋`data/` 快取 |
| 加碼 | 在場時「爆量收黑」用台指期加碼的訊號與持有進度（`overlay_lines()`） | 證交所成交金額 |
| 👀 觀察 | 台指選擇權 Put/Call 未平倉比與提早進場條件（只觀察，不納入策略） | 期交所 |

## 現行策略（v3，2026-11-24）

每週最後一個交易日（通常週五）收盤判斷，下一個交易日收盤成交：

1. **進場**：加權指數收盤 > 60 日均線 × 1.01，且融資不過熱 → 全押 00631L（台灣50正2）
2. **出場**：收盤 < 80 日均線 × 0.975，或融資過熱 → 全部轉現金
3. **融資過熱**（**每天檢查**，持有中任一天成立就隔天收盤出場）：上市融資金額 ÷ 加權指數，比近 250 日平均高 17.5% 以上，**或** z 分數（偏離 ÷ 250 日標準差）> 2
4. **過熱出場後回補**：偏離 < 12.5% 且 z ≤ 2，且指數仍在出場線之上 → 直接回補（不必等進場線）
5. **在場加碼**（另一套規則，見 `overlay_lines()`）：在場時成交金額 ≥ 20 日均 1.5 倍且收黑 → 當晚夜盤加台指期 0.5～1 倍、抱 10 個交易日

回測（2002～2026，不含加碼）：年化約 27%、最大回檔約 -33%；2015-09 後用 00631L 真實價格約 38%、-27%；同期 0050 長抱約 12%。最長曾經 73 個月沒創新高（2011～2017 盤整）。拔靴模擬顯示 2x 在 20 年內回檔超過 50% 的機率不低，詳見研究紀錄。

## 架構

```
report.py                  日報主程式（只用 Python 標準函式庫）
data/*.csv                 快取：taiex_daily、taiex_hourly、pcratio、margin_ratio（每次只抓當天／當月，Actions 跑完 commit 回來）
.github/workflows/
  report.yml               每個交易日 21:30 跑日報並存回 data/；14:40 爆量收黑提醒（觸發才送）
  tg-relay.yml             research/outbox/ 有新檔就代發到 Telegram（雲端研究環境連不到 Telegram 時用）
  tg-inbox.yml             每 10 分鐘把使用者傳給 bot 的訊息存到 research/inbox/
research/
  研究紀錄.md               目標、驗收標準、已研究結論、待研究清單、研究日誌（先讀這份）
  outbox/  inbox/          Telegram 報告與使用者訊息
  tg_send.py  tg_inbox.py
backtest/
  strategy_v3.py           現行策略的回測引擎（與 report.py 一致）
  bt.py  data.py           基礎框架：加權指數 1997～，1x＝指數＋3% 配息，2x＝2×1x−1% 內扣，現金 1%，換手 0.25%
  research_NN_*.py         各研究；結果在 結果_研究NN_*.txt
  build_*.py               下載歷史資料（證交所、期交所、國發會…）
```

## 執行

```bash
# 日報（需要 TG_BOT_TOKEN、TG_CHAT_ID；指定日期測試用 REPORT_DATE）
REPORT_DATE=20261120 python -X utf8 report.py

# 現行策略回測
python -X utf8 backtest/strategy_v3.py
```

Windows 主控台要加 `-X utf8`，否則印 emoji 會出錯。GitHub Secrets：`TG_BOT_TOKEN`、`TG_CHAT_ID`（token 不要寫進倉庫，這是公開倉庫）。
