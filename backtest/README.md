# 回測

`python backtest/bt.py`（基準＋參數掃描）、`python backtest/robust.py`（鄰近參數、壓力測試、各年度）。第一次執行會從 Yahoo 抓資料存成 json。

- 1x ≈ 0050：加權指數漲跌＋每年 3% 配息；2x ≈ 00631L：2 倍再扣每年 1% 內扣（用 00631L 2015-09 之後真實走勢校正，略保守）；現金每年 1%
- Yahoo 的 0050／00631L 早期有錯價（單日 -75%、-95%），所以長期回測用加權指數模擬，真實價格只用 2015-09 之後驗證
- 每週最後一個交易日收盤判斷，下一個交易日收盤成交；每換手 1 單位曝險成本 0.25%
